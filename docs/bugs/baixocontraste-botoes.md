# Baixo contraste nos botões da interface

## Como reproduzir

Acessar a interface da aplicação.

## Resultado esperado

Os botões deveriam possuir contraste suficiente entre:
- cor de fundo
- cor do texto

permitindo fácil leitura.

## Resultado atual

Alguns botões possuem fundo branco com texto em tonalidade muito clara, dificultando a visualização do conteúdo.

## Impacto

A usabilidade da aplicação é prejudicada, podendo dificultar a navegação e acessibilidade para usuários.
